# System Architecture (系統架構圖)

本文件描述 **YT Abstract** 的高層次系統架構與數據流。

## High Level Data Flow

```mermaid
graph TD
    User[User / Browser] -->|1. Input URL & Config| ReactApp[React Frontend]
    
    ReactApp -->|2. HTTP Request / SSE Stream| FastAPI[FastAPI Backend]
    
    subgraph Backend Services
        FastAPI -->|3. Validate & Dispatch| Router[API Router]
        Router -->|4. Download Audio| MediaSvc[Media Service]
        MediaSvc -->|yt-dlp| YouTube[(YouTube)]
        
        Router -->|5. Transcribe| TranscribeSvc[Transcription Service]
        TranscribeSvc -->|Option A: Local| Whisper[Faster-Whisper (GPU)]
        TranscribeSvc -->|Option B: Cloud| GroqAPI[Groq API (Cloud)]
        
        Router -->|6. Summarize| SummarySvc[Summary Service]
        SummarySvc -->|Generate| Gemini[Google Gemini 1.5 Flash]
    end
    
    Backend Services -->|7. SSE Progress Events| ReactApp
    Backend Services -->|8. Final JSON Result| ReactApp
    
    ReactApp -->|9. Render UI| UI_Components
    UI_Components -->|Display| Transcript[Transcript View]
    UI_Components -->|Visualize| Mermaid[Mermaid Mind Map]
    UI_Components -->|Export| Download[Download Markdown]
```

## Component Details

### Frontend (React + Vite)

- **Entry**: `App.tsx` handles the main layout and state machine (Idle -> Downloading -> Transcribing -> Summarizing).
- **Visualization**: `Mermaid.tsx` renders the code blocks generated by Gemini.
- **Communication**: Uses `fetch` with `ReadableStream` to handle Server-Sent Events (SSE) for real-time progress updates.

### Backend (FastAPI)

- **MediaService**: Handles `yt-dlp` operations, temporary file management/cleanup.
- **TranscriptionService**:
  - Abstracts the difference between Local (Whisper) and Cloud (Groq).
  - Normalizes output to a standard Segment format.
- **SummaryService**:
  - Constructs the prompt for Gemini.
  - Enforces JSON/Markdown structure including the Mermaid block.
